Configuration ​

DepGate is configured with environment variables. The names are the same in every production setup: .env in deploy/all-in-one/ and deploy/app-only/ (each has an .env.example that lists them with explanations), and the ConfigMap depgate-config and Secret depgate-secrets in deploy/kubernetes/. Restart DepGate to apply a change: ./3-run.sh with Compose, kubectl rollout restart deployment/depgate on Kubernetes.

Settings that Security users change in the web interface (repositories, single sign-on, email, webhooks, log streaming, the artifact cache, the registry token lifetime and the gateway security controls) are stored in the database and need no restart.

Required ​

VariableDescription
GATEWAY_URLThe address people and package clients use, for example https://depgate.example.com. Download links in registry responses are built from it.
JWT_SECRETSecret that signs sessions and registry tokens. Generate it with openssl rand -hex 32 and keep it: changing it signs everyone out and invalidates every registry token.
ADMIN_EMAILThe first Security account, created on first start on an empty database only. Changing it later does nothing.
ADMIN_PASSWORDIts initial password, read at that first start only. Change it in the web interface afterwards; both variables may then be removed.
DEPGATE_IMAGE, DEPGATE_VERSIONThe image and tag to run (Compose setups; ghcr.io/secmods/depgate and the release version). On Kubernetes: images: in kustomization.yaml.

Caching ​

VariableDefaultDescription
NPM_METADATA_TTL300Seconds npm metadata is considered fresh.
NPM_METADATA_STALE_TTL3600Seconds stale npm metadata may still be served while it is refreshed.
METADATA_TTL, METADATA_STALE_TTLnpm valuesThe same for the other ecosystems.
NPM_NEGATIVE_TTL, METADATA_NEGATIVE_TTL60Seconds a "not found" answer is cached.

Shorter stale windows reduce Redis memory use. See Requirements → Sizing.

Artifact cache ​

Package files from public registries, kept on each replica's local disk. See Artifact cache. Every variable except ARTIFACT_CACHE_DIR is a default: Settings → Artifact cache can change it at runtime.

VariableDefaultDescription
ARTIFACT_CACHE_ENABLEDfalse (true in every production setup in deploy/)Turns the cache on. Settings → Artifact cache can switch it on or off and overrides this value.
ARTIFACT_CACHE_DIR/var/lib/depgate/artifactsCache directory on local SSD. One directory per replica; never share it.
ARTIFACT_CACHE_MAX_SIZE_GBnone, required when enabledMost disk the cache uses on each replica, in GB of 1024³ bytes. DepGate does not start when ARTIFACT_CACHE_ENABLED is true and no size is set here or in Settings. Never more than the disk's free space.
ARTIFACT_CACHE_MAX_FILES200000Most files on each replica.
ARTIFACT_CACHE_MAX_AGE_DAYS30Days after which a stored file is downloaded again. 0 turns it off.
ARTIFACT_CACHE_MAX_IDLE_DAYS7Days without a download after which a file is removed. 0 turns it off.
ARTIFACT_CACHE_MAX_FILE_MB1024Larger files are served but not stored.
