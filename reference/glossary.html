Glossary

On this page

Glossary ​

TermMeaning
ApprovalAn exception scoped to one policy, created from the Monitoring page. Only that policy stops matching the package.
Artifact cachePackage files from public registries kept on each DepGate replica's local disk.
Audit LogThe record of every change a person made in DepGate, every sign-in and every package check.
CI tokenA download-only token minted by a service account for one pipeline job. It lasts at most 1 day.
CVSSCommon Vulnerability Scoring System. A 0–10 severity score: Medium from 4.0, High from 7.0, Critical from 9.0.
Decision LedgerThe record of every download DepGate refused, and why.
Dependency confusionAn attack in which a public package impersonates an internal package name. Prevented by namespace protection.
EcosystemA package format and its clients: npm, PyPI, Maven, Go, NuGet, Cargo, Composer or RubyGems.
EnforceA policy mode in which matching versions are blocked.
EPSSExploit Prediction Scoring System, from FIRST. The daily probability that a CVE will be exploited in the next 30 days.
ExceptionA time-bound permission for a package that policies would block.
Identity providerThe OpenID Connect or SAML service people sign in with when single sign-on is set up.
Internal registryA remote repository that holds your organization's own packages.
Log streamingDelivery of DepGate's events in batches to a SIEM or log platform.
Malware listKnown-malicious packages, from the synced threat feed and your own entries.
Monitor modeA policy mode that records what would be blocked, without blocking.
Namespace protectionA rule that serves your internal package names only from trusted remotes.
OSVOpen Source Vulnerabilities, the vulnerability database DepGate uses.
Package checkThe page and API that show which versions of a package are allowed, and why.
PolicyA rule plus an action (Block or Allow), with a priority, an ecosystem and a repository scope.
PriorityThe order of policy evaluation. Lower numbers first; the first match decides.
Registry tokenThe personal token in a developer's package manager settings.
Remote repositoryA repository that proxies one upstream registry.
ScorecardThe OpenSSF Scorecard, a 0–10 rating of an open-source project's security practices.
Service accountA non-interactive account whose key mints CI tokens.
Virtual repositoryA repository that serves several remotes behind one URL, asking them in order.
Waiver requestA developer's request for an exception, reviewed by the security team.
